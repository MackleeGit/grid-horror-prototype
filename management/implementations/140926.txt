### Phase 1 Core Implementation

#### [MODIFY] [src/main.cpp](file:///c:/Users/PC/OneDrive/Desktop/Nota%20Bene/horror-project/src/main.cpp)

1. **Window Resize Callback (`framebuffer_size_callback`):**
   - Automatically adapts `glViewport(0, 0, width, height)` if the user resizes the window.
2. **Delta Time System:**
   - Track `deltaTime` and `lastFrame` using `glfwGetTime()` at the start of each frame.
   - Scale player movement speed by `deltaTime` for framerate-independent movement.
3. **FPS Camera Mathematical State (GLM):**
   - Include `<glm/glm.hpp>` and `<glm/gtc/matrix_transform.hpp>`.
   - Maintain state variables:
     - `cameraPos`: Initialized at `(0.0f, 0.0f, 3.0f)`
     - `cameraFront`: Initialized at `(0.0f, 0.0f, -1.0f)`
     - `cameraUp`: `(0.0f, 1.0f, 0.0f)`
     - `yaw`: `-90.0f` (facing down negative Z)
     - `pitch`: `0.0f`
4. **Mouse Callback & Pitch/Yaw Spherical Trigonometry:**
   - Capture cursor with `glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_DISABLED)`.
   - Register `mouse_callback(GLFWwindow* window, double xpos, double ypos)`.
   - Calculate pitch and yaw offsets multiplied by sensitivity.
   - Clamp pitch between `-89.0f` and `89.0f` to prevent gimbal lock / screen flip.
   - Recalculate the `cameraFront` unit vector:
     $$\begin{aligned}
     x &= \cos(\text{yaw}) \cdot \cos(\text{pitch}) \\
     y &= \sin(\text{pitch}) \\
     z &= \sin(\text{yaw}) \cdot \cos(\text{pitch})
     \end{aligned}$$
5. **Keyboard Input Processing (`processInput`):**
   - Query `GLFW_KEY_W`, `GLFW_KEY_S`, `GLFW_KEY_A`, `GLFW_KEY_D`.
   - Translate `cameraPos` along `cameraFront` and the orthogonal cross product `cameraRight = normalize(cross(cameraFront, cameraUp))`.
   - Handle `GLFW_KEY_ESCAPE` to gracefully close the window.
6. **Construct the View Matrix:**
   - Every frame in the render loop, compute:
     ```cpp
     glm::mat4 view = glm::lookAt(cameraPos, cameraPos + cameraFront, cameraUp);
     ```
